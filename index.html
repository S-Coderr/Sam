The organisation that invited you to complete this assessment is the data controller for your personal data. It decides why and how your data is processed and how long it is kept.

Your personal data may be shared with the employer that invited you to this assessment and with trusted service providers who host and support the assessment platform, always under appropriate safeguards.
You can reach our Data Protection Officer at privacy@shl.com for any questions about this Notice or how your personal data is processed.

        About this portal

        This is a working clone of the SHL AMCAT test-delivery portal, built from real screen
        photos. It contains 8 assessments with a real question bank:
        
    
          
  • English Comprehension (18 questions), Logical Ability (12), Quantitative Ability (16)
    • 
          
  • Personality (72 statements on a 5-point scale)
    • 
          
  • Computer Programming (25), Computer Science (20)
    • 
          
  • Automata Pro (2 coding problems) & Automata Fix (7 debug-the-code problems)
    • 
        

        

        Controls
        
    
          
  • The timer at the top counts down per section; when it reaches zero the section auto-submits.
    • 
          
  • Use the numbered rail on the right to jump between questions (green = answered).
    • 
        

      

      

        
      

    

  


  

    

      
Show tips

      

        Coding tips
        
    
          
  • Read the input strictly in the format described — extra printing causes test cases to fail.
    • 
          
  • Do not print prompt messages like “Enter a number”; print only the required output.
    • 
          
  • Use the sample test case to verify your logic before submitting.
    • 
          
  • Watch the constraints — prefer O(n) or O(n log n) algorithms for large inputs.
    • 
          
  • You can use cout / printf to debug, but remove debug prints before submitting.
    • 
        

      

      

        
      

    

  


  
  

    

      
Data Protection Notice

      

        This demo portal stores the candidate details you enter (name, participant ID and language
        preferences) only in this browser's local storage. Nothing is transmitted to any server or
        third party.
        


        The information is used solely to personalise your test experience within this clone, for
        example by displaying your name and participant ID in the menu panel.
        


        You may review or edit your details at any time via the menu (≡) →
        Edit details.
